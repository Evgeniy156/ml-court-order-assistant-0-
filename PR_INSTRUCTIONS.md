```markdown
## Исправления для ДЗ №5

### Проблема
При тестировании обнаружено, что при ошибке постановки задачи в очередь или ошибке выполнения задачи пользователь терял кредиты без возврата.

### Решение

#### 1. Возврат средств при ошибке публикации в RabbitMQ
- При ошибке публикации в RabbitMQ выполняется `db.rollback()` транзакции
- Все изменения (создание задачи и списание кредитов) откатываются
- Кредиты не списываются, пользователь получает понятное сообщение об ошибке

**Файл:** `app/src/routers/predict.py`
- Убрана дублирующая проверка баланса
- Добавлен `task_id` в `task_data` для worker
- Улучшено логирование операций

#### 2. Возврат средств при ошибке выполнения задачи
- При ошибке выполнения задачи в worker вызывается `refund_credits()`
- Кредиты возвращаются пользователю через отдельную транзакцию
- Статус задачи обновляется на `failed`
- Добавлено подробное логирование

**Файл:** `app/src/worker/worker.py`
- Добавлена обработка ошибок с возвратом кредитов
- Улучшено логирование ошибок

#### 3. Очистка кода
- Убраны лишние пробелы перед точками во всех файлах
- Удалены `__pycache__` директории
- Исправлены стилистические ошибки

**Измененные файлы:**
- `app/src/routers/predict.py`
- `app/src/worker/worker.py`
- `storage/repository.py`
- `app/src/services/auth.py`
- `app/src/schemas/__init__.py`

### Результат
✅ При ошибке публикации в RabbitMQ кредиты не списываются (rollback транзакции)
✅ При ошибке выполнения задачи кредиты возвращаются через `refund_credits()`
✅ Система ведет себя справедливо и предсказуемо
✅ Все тесты проходят: `pytest tests/` → 19 passed
```
